The book note is a plain Markdown note. It holds the details of the book, its design, its reading order and custom CSS.

## A full book note

````md
---
orca-book: 1
title: Twenty Thousand Leagues Under the Sea
author: Jules Verne
language: "en-GB"
fonts:
  - Alegreya
trim: 5.5in 8.5in
body-font: EB Garamond
body-size: 10.5pt
chapter-drop-cap: 3
header-left-page: author
header-right-page: chapter-title
---

# Front matter

- `title-page`
- [[Copyright]] `copyright`
- `contents`

# Body

- [[Part One]] `part`
- [[A Shifting Reef]]
- [[Pro and Con]]

# Back matter

- [[A note on the text]] `back-matter`

```css
section.chapter h1 {
  margin-bottom: 56pt;
}
```
````

## Frontmatter

The frontmatter starts with `orca-book: 1`. The keys after it are the details of the book:

| Key | Value |
| --- | --- |
| `title` | The title of the book |
| `author` | The author |
| `language` | A language tag, for example `en-GB` |
| `date` | The date of the book |
| `publisher` | The publisher |
| `series` | The series |
| `isbn` | The ISBN |
| `cover` | The image an EPUB shows as its cover, as a path in the vault or a link to the image |
| `identifier` | The name that tells this book from every other. Orca writes it and it stays the same |

The `fonts` key holds the fonts that the Fonts group of the design panel adds, one name per item, so that custom CSS can use them. [Fonts](/design/fonts/) shows how to add one.

The `navigator-headings` key holds the deepest heading level that the navigator lists for this book. A value from `1` to `6` is a level, and `0` hides the headings. A note without the key uses the `Headings in the navigator` setting.

The frontmatter also stores the design keys. A full description of all supported design keys can be found [here](/reference/design-keys/).

## Reading order

The body of the note is the reading order. A list item is one entry. An entry links to a note. An entry can also have a role, in backticks after the link. A role is the kind of entry, for example `copyright` or `part`.

```md
- [[Copyright]] `copyright`
- [[Part One]] `part`
- [[A Shifting Reef]]
```

An entry with no role is a chapter. An entry with a generated role needs no link, because orca makes the text of that entry.

```md
- `title-page`
- `contents`
```

## Sections

A heading starts a section, for example `# Front matter` or `# Body`. Sections group the entries in the navigator. They do not change the typeset book. The role of an entry sets how orca typesets it, in any section.

## Roles

| Role | Name | Text | Effect |
| --- | --- | --- | --- |
| `title-page` | Title page | Generated | Sets the title and the author from the book's details. The text of a linked note is not set. |
| `copyright` | Copyright | From a note | A single page in small type, at the foot of the page. The contents does not list it. |
| `dedication` | Dedication | From a note | A single page, centered and down the page. The contents does not list it. |
| `epigraph` | Epigraph | From a note | A single page to a narrow measure, with its last paragraph set to the right. |
| `contents` | Contents | Generated | Lists the parts, the chapters and the other prose with their pages. The text of a linked note is not set. |
| `front-matter` | Front matter | From a note | Prose that is not a chapter, such as a preface. The contents lists it, and it takes no drop cap. |
| `part` | Part | From a note | A title page for a group of chapters. The first part or chapter is page 1. |
| `chapter` | Chapter | From a note | A chapter of the body. The first part or chapter is page 1. |
| `back-matter` | Back matter | From a note | Prose that is not a chapter, such as an afterword. The contents lists it, and it takes no drop cap. |

The first part or chapter of the book is page 1. The pages before it are numbered in lower-case roman, for example `iii`. The pages from page 1 to the end use the format that the design sets. A role does not change this, so a `front-matter` entry after the last chapter has an arabic page number.

The contents lists each `part`, `chapter`, `front-matter` and `back-matter` entry. An entry before page 1 shows its page number in roman.

[Roles](/start/roles/) shows how to pick a role for each note.

## Book CSS

A `css` code block in the note contains custom CSS for advanced overrides. The CSS view of the design panel edits this block. The [fleuron CSS subset](https://fleuron.typeworks.dev/css-subset/) lists the CSS that Orca supports. [Custom CSS](/design/custom-css/) shows how to write it.

```css
section.chapter h1 {
  margin-bottom: 56pt;
}
```
