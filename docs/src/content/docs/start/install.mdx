Orca is a plugin for Obsidian on the desktop. It needs Obsidian 1.7.2 or later. Orca is in Obsidian's list of community plugins.

## Install orca

1. Open `Settings`.
2. Open `Community plugins`.
3. If community plugins are off, select `Turn on community plugins`.
4. Select `Browse`.
5. Search for `Orca`.
6. Select `Orca` in the results.
7. Select `Install`.
8. Select `Enable`.

The ribbon then shows `Open Orca`. The menu for a folder in the file tree then has `Create book from these notes`. Next, read [Anatomy of orca](/start/anatomy/) to learn the parts of orca.

## Install a build that is not released

A build of orca has three files: `main.js`, `manifest.json` and `styles.css`. Copy them into the vault to use a build that the list of community plugins does not have.

1. In the vault, make the folder `.obsidian/plugins/orca/`.
2. Copy the three files into that folder.
3. Restart Obsidian.
4. Open `Settings`.
5. Open `Community plugins`.
6. Turn on `Orca`.
