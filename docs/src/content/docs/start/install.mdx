## Install orca

1. Open `Settings`.
2. Open `Community plugins`.
3. If community plugins are off, select `Turn on community plugins`.
4. Select `Browse`.
5. Search for `Orca`.
6. Select `Orca` in the results.
7. Select `Install`.
8. Select `Enable`.

The ribbon then shows `Open Orca`. The menu for a folder in the file tree then has `Create book from these notes`. Next, read [Anatomy of orca](/start/anatomy/) to learn the parts of orca.

## Install another version

[BRAT](https://github.com/TfTHacker/obsidian42-brat) is a community plugin that installs a plugin from its GitHub repository. With BRAT, you can install a version of orca that is not the one in the list of community plugins. The repository to give BRAT is `zachhannum/obsidian-orca`.
