To export the book, select <Action name="export" /> in the header of the preview, or run the command `Export book`.

## Export the book

<Shot
  name="export"
  alt="The Export book dialog, with Formats, Save to, Choose, Preflight showing No errors, and Export."
  caption="The Export book dialog, ready to export."
/>

1. In `Formats`, select each format to write. Orca writes one file for each format.
2. In `Save to`, edit the path of the files, without the extension. By default, the files have the name of the book and are beside the book note.
3. To save the files in a folder outside the vault, select `Choose…`.
4. When `Preflight` shows `No errors`, select `Export`.

A reading system makes the pages of an EPUB. So the preview shows the pages of the PDF, not the pages of the EPUB.

## Preflight errors

Preflight finds the errors that stop an export. You cannot export until you fix them.

| Error | Action |
| --- | --- |
| `Missing font: <name>` | `Change font…` |
| `Cannot read font file: <name>` | `Change font…` |
| `Missing image: <url>` | `Go to line` |
