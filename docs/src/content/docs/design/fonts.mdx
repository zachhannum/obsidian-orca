The Fonts group in the design panel adds fonts to the book. Orca loads these fonts into the engine. Your custom CSS can then set text in them.

## Add a font

1. In the Fonts group, select `Add a font`.
2. Type part of the name of the font. The list shows the fonts on this machine.
3. Select the font in the list.

## Fonts on a phone or a tablet

On an iPhone or an iPad, the list shows the fonts of the system and the fonts in the `fonts` folder of the vault. On Android, the list shows only the fonts in the `fonts` folder of the vault.

To use a font that the device does not have, copy its font files into the `fonts` folder. If orca can read no font on the device, the list shows the one font that orca has built in.

## Set text in the font

In the CSS view of the panel, set `font-family` to the font:

```css
section.dedication p {
  font-family: "Alegreya";
}
```

## A font this machine does not have

If you open the book on a machine without an added font, the panel shows a warning under the groups:

```text
Missing font: Alegreya
```
