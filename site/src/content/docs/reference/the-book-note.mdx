The book note is a plain Markdown note. It holds the details of the book, its design, its reading order and its own CSS. The navigator and the design panel write it.

## Frontmatter

The frontmatter starts with `orca-book: 1`. The keys after it are the details of the book:

| Key | Value |
| --- | --- |
| `title` | The title of the book |
| `author` | The author |
| `language` | A language tag, for example `en-GB` |
| `date` | The date of the book |
| `publisher` | The publisher |
| `series` | The series |
| `isbn` | The ISBN |

The design keys come after these keys. [Design keys](/reference/design-keys/) lists them.

## Reading order

/>

The body of the note is the reading order. A heading starts a section, for example `# Front matter` or `# Body`. A list item under a heading is one entry. An entry links to a note. An entry can also have a role, in backticks after the link. A role is the kind of entry, for example `copyright` or `part`.

```md
# Front matter

- `title-page`
- [[Copyright]] `copyright`
- `contents`

# Body

- [[Part One]] `part`
- [[A Shifting Reef]]
```

An entry with no role is a chapter. An entry with a generated role needs no link, because orca makes the text of that entry.

## Roles

| Role | Name | Text |
| --- | --- | --- |
| `title-page` | Title page | Generated |
| `copyright` | Copyright | From a note |
| `dedication` | Dedication | From a note |
| `epigraph` | Epigraph | From a note |
| `contents` | Contents | Generated |
| `front-matter` | Front matter | From a note |
| `part` | Part | From a note |
| `chapter` | Chapter | From a note |
| `back-matter` | Back matter | From a note |

## Book CSS

A `css` code block in the note holds the CSS of the book. Orca applies it after the CSS that the design panel makes. The panel does not write this block.
