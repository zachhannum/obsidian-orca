Orca writes the book to a PDF from the same pages that the preview shows.

## Open the dialog

Do one of these steps:

- In the preview header, select `Export to PDF`.
- Run the command `Export to PDF`.

## Export the book

<Shot
  name="export"
  alt="The Export to PDF dialog, with Save to, Choose, Preflight showing No errors, and Export."
  caption="The Export to PDF dialog, ready to export."
  marks={['destination', 'choose', 'fine', 'write']}
  numbered
/>

1. `Save to` is the file that orca writes. It starts as the book title with `.pdf`, beside the book note. To change it, edit the path.
2. To write the file outside the vault, select `Choose…`. The system save dialog opens.
3. Under `Preflight`, wait until `Checking…` changes to `No errors`.
4. Select `Export`.

## Preflight errors

If preflight finds an error, orca shows a card for it and does not export. The footer shows `Fix N errors to export`, where N is the number of errors.

| Error | Action |
| --- | --- |
| `Missing font: <name>` | `Change font…` |
| `Cannot read font file: <name>` | `Change font…` |
| `Missing image: <url>` | `Go to line` |

After export, the dialog shows the file name, the page count and the file size. To open the file, select `Open PDF`. To close the dialog, select `Done`.
