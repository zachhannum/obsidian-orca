A chapter is a note, and you write it in the Obsidian editor. The preview shows the same chapter as set pages.

## Open the preview

<Shot
  name="write"
  alt="A chapter open in the Obsidian editor, with Open preview in the header."
  caption="A chapter in the editor."
  marks={['open-preview']}
/>

1. Open a note that is in a book.
2. In the header, select `Open preview`.

The same pane then shows the set pages of the chapter.

## Read the set pages

<Shot
  name="read"
  alt="The preview of a chapter, with Export to PDF, Inspect the page and Open as markdown in the header."
  caption="The preview, with its actions in the header."
  marks={['export', 'inspect', 'as-markdown']}
  numbered
/>

The preview has three actions in its header:

1. `Export to PDF` opens the export dialog.
2. `Inspect the page` turns inspect mode on or off.
3. `Open as markdown` shows the chapter in the editor again.

## Commands

| Command | Result |
| --- | --- |
| `Open preview to the right` | Opens the preview of the current chapter in a new pane to the right. |
| `Open manuscript to the left` | Opens the note of the previewed chapter in a new pane to the left. |
| `Next chapter` | Turns the preview to the next chapter in reading order. |
| `Previous chapter` | Turns the preview to the previous chapter in reading order. |

[Export to PDF](/export/export-to-pdf/) shows how to write the book to a file.
