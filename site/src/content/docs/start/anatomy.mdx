Orca adds three new panes to Obsidian.

<Shot

1. `Open Orca` in the ribbon shows the navigator.
2. The navigator lists each book in the vault and its notes in reading order. [Make a book](/start/make-a-book/) shows how to use it.
3. The preview shows the book as typeset pages. [The preview](/start/the-preview/) shows how to use it.
4. The design panel sets how the book looks. The preview shows each change. [The design panel](/design/overview/) shows how to use it.
