A book is a folder of notes and one book note that lists them in reading order. Orca makes the book note from the folder.

## Make a book from a folder

<Shot
  name="make-menu"
  alt="The file tree with the menu for a folder open, and Create book from these notes in the menu."
  caption="The menu for a folder in the file tree."
  marks={['create']}
  numbered
/>

1. In the file tree, right-click the folder that holds the chapters.
2. Select `Create book from these notes`.

Orca writes a book note beside the folder, in the parent folder. The name of the note and its `title` are the name of the folder. Under the heading `# Body`, the note links to every note in the folder, sorted by name. The headings `# Front matter` and `# Back matter` are empty.

Orca then opens the book note.

To start a book with no notes, run the command `New book`. The command writes a book note with the name `Untitled book`.

## The new book

<Shot
  name="make-navigator"
  alt="Orca's navigator in the left sidebar, with the new book and its chapters under it."
  caption="The navigator, with the new book in it."
  marks={['book']}
/>

The navigator shows the new book and its notes in reading order. To show the navigator, select `Open Orca` in the ribbon. To change the reading order, drag a note to a new place in the navigator.

<Shot
  name="make-page"
  alt="The new book note open as a book page, with Open as markdown and Open preview in the header."
  caption="The book note, open as a book page."
  marks={['as-markdown', 'open-preview']}

The book note opens as a book page. The book page has two actions in its header:

1. `Open as markdown` shows the note as text.
2. `Open preview` shows the book as typeset pages, laid out as they print.

The book note is plain Markdown. [The book note](/reference/the-book-note/) shows its format. [Write with the preview](/start/write-with-the-preview/) is the next step.
