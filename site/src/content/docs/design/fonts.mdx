The Fonts group in the design panel adds fonts to the book, beyond the ones the controls use. Orca loads these fonts into the engine. Your custom CSS can then set text in them.

<Shot
  name="panel-fonts"
  alt="The Fonts group of the design panel, with the Add a font picker under the heading."
  caption="The Fonts group, with no font added yet."
/>

## Add a font

1. In the Fonts group, select `Add a font`.
2. Type part of the name of the font. The list shows the fonts on this machine.
3. Select the font in the list.

## Set text in the font

In the CSS view of the panel, set `font-family` to the font:

```css
section.dedication p {
  font-family: "Alegreya";
}
```

## A font this machine does not have

If you open the book on a machine without an added font, the panel shows a warning under the groups:

```text
Alegreya is not a font this machine has. The book is set in the one orca carries.
```
