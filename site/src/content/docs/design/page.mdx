## Controls

| Control | Default | Key |
| --- | --- | --- |
| Trim | `US trade (6 × 9 in)` | `trim` |
| Margins inside | `0.75in` | `margin-inside` |
| Margins outside | `0.6in` | `margin-outside` |
| Margins top | `0.75in` | `margin-top` |
| Margins bottom | `0.75in` | `margin-bottom` |
| Mirror the margins on facing pages | on | `mirrored` |

## Trim

The trim is the size of the page. `Trim` offers these sizes by name:

| Name | Size |
| --- | --- |
| `Mass market` | 4.25 × 6.87 in |
| `Digest` | 5.5 × 8.5 in |
| `Novel` | 5.25 × 8 in |
| `US trade` | 6 × 9 in |
| `Demy` | 129 × 198 mm |
| `Royal` | 156 × 234 mm |
| `A5` | 148 × 210 mm |

A custom trim takes a width and a height.

## Margins

The inside margin is the margin at the spine. When `Mirror the margins on facing pages` is on, a left page and a right page swap the inside and outside margins.

A number field takes a number and a unit: `pt`, `pc`, `in`, `mm`, `cm` or `em`. A number with no unit is in points.

## Page measurements

The setting `Page measurements` sets the unit that the panel shows the trim and margins in. The values are `Inches`, `Millimeters` and `Points`.

## In the book note

Each control that you change writes one key to the frontmatter of the book note.

```yaml
trim: 5.5in 8.5in
margin-inside: 0.95in
margin-outside: 0.7in
margin-top: 0.8in
margin-bottom: 1in
```
