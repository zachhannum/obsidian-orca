The Headings group in the design panel sets the font, size and alignment of each heading level. A chapter title is a level 1 heading.

## Controls

In a key, `N` is the heading level, from 1 to 6.

| Control | Default | Key |
| --- | --- | --- |
| Font | `EB Garamond` | `heading-N-font` |
| Variant | The default variant of the font | `heading-N-font-variant` |
| Size | `19pt` | `heading-N-size` |
| Alignment | `Left` | `heading-N-align` |

## Pick a level

1. Select a level in the strip, from `H1` to `H6`.
2. Change the controls under the strip.

The strip writes no key. The controls under it write the keys for the level that you selected.

If a level has no font of its own, it uses the font from the Text group.

## In the book note

Each control that you change writes one key to the frontmatter of the book note.

```yaml
heading-1-size: 16pt
heading-1-align: center
heading-2-size: 9pt
heading-2-align: center
```
