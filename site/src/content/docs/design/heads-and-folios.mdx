A running head is the line at the top of a page, and a folio is the page number. The Heads & folios group in the design panel sets both.

## Controls

| Control | Default | Key |
| --- | --- | --- |
| Left-page header | `Nothing` | `header-left-page` |
| Right-page header | `Nothing` | `header-right-page` |
| Header position | `Outside` | `header-position` |
| Page number | `Bottom` | `page-number-position` |
| Number format | `1, 2, 3` | `page-number-format` |
| Hide the running head and page number on openings | on | `suppress-head-on-openings` |

## Running heads

`Left-page header` and `Right-page header` each take `Nothing`, `Author`, `Book title` or `Chapter title`. `Header position` sets the head at the outside edge of the page or in the center.

<Page n={12} alt="A left page of the sample book, with the author's name at the top and the page number at the bottom." caption="A left page in the sample book, with the author as its running head." />

## Page numbers

`Page number` sets the folio at the top, at the bottom, or at the outside edge. `Number format` sets the folio in arabic numerals or in lowercase roman numerals.

An opening is the first page of a chapter. When `Hide the running head and page number on openings` is on, an opening has no running head and no folio.

## In the book note

Each control that you change writes one key to the frontmatter of the book note.

```yaml
header-left-page: author
header-right-page: chapter-title
```
