A running head is the line of text at the top of a page, such as the book title or the chapter title. A folio is the page number. The Heads & folios group in the design panel sets both.

## Controls

| # | Control | Default | Key |
| --- | --- | --- | --- |
| 1 | Left-page header | `Nothing` | `header-left-page` |
| 2 | Right-page header | `Nothing` | `header-right-page` |
| 3 | Header position | `Outside` | `header-position` |
| 4 | Page number | `Bottom` | `page-number-position` |
| 5 | Number format | `1, 2, 3` | `page-number-format` |
| 6 | Header font | `EB Garamond` | `header-font` |
| 7 | Folio font | `EB Garamond` | `folio-font` |
| 8 | Capitals | `Normal` | `header-caps` |
| 9 | Tracking | `None` | `header-letter-spacing` |
| 10 | Set the running heads in italic | off | `header-italic` |
| 11 | Hide the running head and page number on openings | on | `suppress-head-on-openings` |

## Fonts

Unless you pick a font, the running heads and the folio use the font from the Text group.

## Capitals, tracking and italic

These three controls set the folio as well as the running heads. Capitals do not change digits.

## Openings

An opening is the first page of a chapter.
