A running head is the line of text at the top of a page, such as the book title or the chapter title. A folio is the page number. The Heads & folios group in the design panel sets both.

## Controls

| # | Control | Default | Key |
| --- | --- | --- | --- |
| 1 | Left-page header | `Nothing` | `header-left-page` |
| 2 | Right-page header | `Nothing` | `header-right-page` |
| 3 | Chapter title from | `First heading` | `chapter-title-from` |
| 4 | Header position | `Outside` | `header-position` |
| 5 | Page number | `Bottom` | `page-number-position` |
| 6 | Number format | `1, 2, 3` | `page-number-format` |
| 7 | Header font | `EB Garamond` | `header-font` |
| 8 | Folio font | `EB Garamond` | `folio-font` |
|  | Header style | `Normal` | `header-style` |
|  | Folio style | `Normal` | `folio-style` |
| 9 | Capitals | `Normal` | `header-caps` |
| 10 | Tracking | `None` | `header-letter-spacing` |
| 11 | Hide the running head and page number on openings | on | `suppress-head-on-openings` |

## The chapter title

By default, running head set to `Chapter title` reads the section's first heading, whatever level it is written at.

The `Chapter title from` option picks the level to read instead. A chapter with no heading at that level reads its first heading instead.

## Fonts and styles

Unless you pick a font, the running heads and the folio use the font from the Text group.

`Header style` sets the weight and the slope of the running heads, and `Folio style` sets them for the page number. Each control has a button for bold and a button for italic, and pressing both sets bold italic.

## Capitals and tracking

These two controls set the folio as well as the running heads. Capitals do not change digits.

## Openings

An opening is the first page of a chapter.
