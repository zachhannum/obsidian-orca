A block quote is a passage a chapter sets apart from the narration: a letter, an epigraph, or words the narrator quotes. You write one in markdown with a `>` before each line. The Quote group in the design panel sets the type of every block quote in the book, and the space around it.

## Controls

| # | Control | Default | Key |
| --- | --- | --- | --- |
| 1 | Font | `EB Garamond` | `quote-font` |
|  | Variant | the default variant of the font | `quote-font-variant` |
| 2 | Size | 11pt | `quote-size` |
| 3 | Indent, left | `2em` | `quote-indent-left` |
|  | Indent, right | `2em` | `quote-indent-right` |
| 4 | Space above | 1 line | `quote-space-above` |
| 5 | Space below | 1 line | `quote-space-below` |

## Font and size

A quote that sets no font of its own is set in the body font, and a quote that sets no size of its own is set at the body size. Both rows show that inherited value faint. If you set either one, the quote keeps it and the body no longer decides it.

The `Variant` row shows only for a font whose faces come in more than one variant.

## Indent and space

`Indent, left` and `Indent, right` set the indent on each side of a quote. A quote indented on both sides sits narrower than the text around it, which is how a quote reads as a quote.

`Space above` and `Space below` are counts of lines of body text, so a quote stays on the same rhythm as the text around it.
