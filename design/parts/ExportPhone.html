A path in the vault. The field holds a path in the vault, and the author can change it. There is no Choose…, because a phone has no save dialog to open.
Export or Share. Export writes the ticked formats into the vault. Share makes the same files and hands them to the system share sheet under the book's file name, and writes none of them. A device that cannot share a file shows no Share.
A share the author cancels leaves the dialog as it was, with no error. A share that goes through closes the dialog. The system opens the share sheet from a tap alone, so the dialog makes the files once preflight passes. Until they are made, Share is off, and the dialog draws B's bar over a line that names the file it is preparing. Export writes those same files. Where the system still refuses the tap, the dialog lists the files it made, as C does without the vault, over Share and Done.
Preflight and length are the desktop's. The list of errors scrolls when the sheet has no room for all of it, and the formats, the path and the buttons stay in place. The fix in a preflight row is a link. It closes the dialog and goes to the control or the line.
A sheet, as Obsidian draws its own. The dialog is docked to the foot of the screen under a grabber. A tap on the grabber, a pull on the title or a tap outside the sheet closes it. With the keyboard up, the sheet ends above the keyboard. A sheet is never as tall as the screen, so the page stays in sight over it.
