Four states worth designing rather than discovering

The frames are what the writer sees. The note under each is for us.
1 Opening a long book for the first time
Setting Pride and Prejudice
18 chapters of 24
it will open at Chapter Twelve
A whole book has to be laid out before any page of it is right, and the first one has nothing cached. It happens once a session, and it needs a state rather than an empty pane.
2 The layout falls over
Setting the book again
nothing you wrote was lost
you will come back to page 147
Orca still holds everything it sent, so recovery is deterministic and needs no decision from the author. The words never lived here in the first place — they are notes in the vault.
3 A book from a newer orca
This book was made by a newer
version of orca than this one.
orca reads format 1, and this book
is written in format 2
Update the plugin to open it
Open as markdown
The key that makes a note a book also says which format it is in, so an older orca can refuse cleanly instead of writing a shape it does not understand.
4 The note changed under an edit
The book changed on disk
This note was written outside orca,
and orca is holding an edit that is not in it.
Take what is on disk
Keep my edit
The view is the only writer while it is open. A change from outside reloads a view holding nothing, and is two versions of one note for a view holding an edit.
