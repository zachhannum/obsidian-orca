A property is edited where it is. A tap on a value brings up the keyboard, and the note is written when the edit settles. A label sits beside its value while the two fit on a line.
Export is a button the width of the page. It opens the export dialog, as the action in the preview's bar does.
The design is read here, and set in the drawer. It has one block for each group of the panel, with the name of the group over its values. A value left at its default is muted. The reading order is read-only on every platform. A row marks nothing under a finger, because a touch has no pointer to follow.
The cover is a picture, not a line of text. A tap on it opens the vault's images in a picker, and the x clears it. A phone has no drag, so the picker is the one way in.
