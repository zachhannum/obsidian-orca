Install

Orca is a plugin for Obsidian on the desktop. It needs Obsidian 1.7.2 or later. Orca is not in the list of community plugins yet.

Copy the plugin into the vault

Section titled “Copy the plugin into the vault”

A build of orca has three files: main.js, manifest.json and styles.css.

  1. In the vault, make the folder .obsidian/plugins/orca/.
  2. Copy the three files into that folder.
  3. Restart Obsidian.

Turn on orca

Section titled “Turn on orca”
  1. Open Settings.
  2. Open Community plugins.
  3. If community plugins are off, select Turn on community plugins.
  4. Turn on Orca.

The ribbon then shows Open Orca. The menu for a folder in the file tree then has Create book from these notes. Next, read Anatomy of orca to learn the parts of orca.
