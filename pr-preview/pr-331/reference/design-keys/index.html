Reference

Design keys

Each control in the design panel writes one key to the frontmatter of the book note. If the note does not have a key, orca uses the default of that key. In a key, N is a heading level, from 1 to 6.

Key Values Reference
trim A width and a height, for example 6in 9in Page
margin-inside A length Page
margin-outside A length Page
margin-top A length Page
margin-bottom A length Page
body-font A font family Text
body-font-variant A variant of the font Text
body-size A length Text
body-line-spacing A length Text
body-align left, center, right, justify Text
body-first-line-indent A length Text
body-indent-after-break true, false Text
body-hyphens true, false Text
body-hanging-punctuation true, false Text
body-orphans A count of lines Page breaks
body-widows A count of lines Page breaks
keep-heading-with-text true, false Page breaks
heading-N-font A font family Headings
heading-N-font-variant A variant of the font Headings
heading-N-style normal, bold, italic, bold-italic Headings
heading-N-size A length Headings
heading-N-caps normal, small-caps, all-caps Headings
heading-N-letter-spacing A length Headings
heading-N-align left, center, right Headings
heading-N-space-above A count of lines Headings
heading-N-space-below A count of lines Headings
chapter-begins next-page, right-page, same-page Chapter openings
chapter-drop-cap 0, 2, 3, 4 Chapter openings
chapter-drop-cap-font A font family Chapter openings
chapter-drop-cap-style normal, bold, italic, bold-italic Chapter openings
chapter-first-line-caps normal, small-caps, all-caps Chapter openings
chapter-first-line-letter-spacing A length Chapter openings
scene-break-mark space, ornament Scene breaks
scene-break-ornament A glyph Scene breaks
scene-break-font A font family Scene breaks
scene-break-style normal, bold, italic, bold-italic Scene breaks
scene-break-size A length Scene breaks
scene-break-space-above A count of lines Scene breaks
scene-break-space-below A count of lines Scene breaks
header-left-page none, author, book-title, chapter-title Headers & page numbers
header-right-page none, author, book-title, chapter-title Headers & page numbers
chapter-title-from first, h1, h2, h3, h4, h5, h6 Headers & page numbers
header-position outside, center Headers & page numbers
page-number-position top, bottom, outside Headers & page numbers
page-number-format arabic, roman Headers & page numbers
header-font A font family Headers & page numbers
folio-font A font family Headers & page numbers
header-style normal, bold, italic, bold-italic Headers & page numbers
folio-style normal, bold, italic, bold-italic Headers & page numbers
header-caps normal, small-caps, all-caps Headers & page numbers
header-letter-spacing A length Headers & page numbers
suppress-head-on-openings true, false Headers & page numbers

A length is a number and a unit: pt, pc, in, mm, cm or em. A number with no unit is in points.
